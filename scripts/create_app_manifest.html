🎓 SCSSA-UoK GitHub App 1-Click Setup

This page pre-configures your GitHub App with the exact permissions required by the automation system.

Step 1: Click the button below. You will be redirected to GitHub with all required permissions pre-selected.
Step 2: On GitHub, click Create GitHub App at the bottom.
Step 3:
  • Note your numeric App ID.
  • Click Generate a private key (saves a .pem file).
  • Click Install App in the sidebar → Install into SCSSA-UoK.
